HIRNLAGER – Prototyp 1

Die Dateien sind eine Web-App. Für Mikrofon und Installation als App muss sie über HTTPS bereitgestellt werden (z. B. GitHub Pages oder Netlify). Das bloße Öffnen von index.html aus dem ZIP bietet nicht zuverlässig Spracherkennung oder Installation.

1. ZIP entpacken.
2. Den Inhalt des Ordners auf einem HTTPS-Webhost veröffentlichen.
3. URL in Chrome auf Android öffnen und ggf. über das Browsermenü „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen.
4. Mikrofonberechtigung erteilen.

Aktueller Umfang: Sprache-zu-Text (sofern Browser unterstützt), Texteingabe, einfache lokale Stichwort-Kategorisierung, Suchfunktion, Kategorien ändern, Bearbeiten, Löschen, JSON-Sicherung/Import und Text-Export.

Noch NICHT enthalten: KI-Kategorisierung, Speicherung von Audio, Sprachaktivierung per „Hey Google“, Synchronisierung über Geräte. Sprachtranskription kann vom Browser über einen externen Spracherkennungsdienst verarbeitet werden. Keine vertraulichen Informationen ohne Prüfung der Datenschutzanforderungen diktieren.
